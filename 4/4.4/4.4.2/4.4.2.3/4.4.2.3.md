# 4.4.2.3. Consultas No Relacionales: Módulo 3 (MUÑOZ) — Estudiantes y matrícula

Las siguientes tres consultas fueron desarrolladas en **MQL** sobre la base de datos `ruta_academica` en **MongoDB 7.0** por **Muñoz**, cubriendo las necesidades del **Módulo 3: Estudiantes y matrícula**.

---

### Q-07. Consultar el seguimiento de riesgo de un estudiante específico

**Propósito:** Permite al estudiante y a su tutor ver el estado de riesgo actual en todas las secciones del ciclo (RF-19, RF-22).

```javascript
// Q-07: Seguimiento de riesgo del estudiante 20191235B (Rodrigo Silva)
db.seguimiento_riesgo.find(
  {
    "estudiante.codigo": "20191235B"
  },
  {
    _id: 0,
    "seccion.curso_codigo":   1,
    "seccion.curso_nombre":   1,
    "seccion.codigo_seccion": 1,
    "ciclo.periodo":          1,
    "indicador":              1,
    "alertas":                1,
    "numero_matricula_curso": 1,
    "historial_asistencia_reciente": 1,
    "fecha_actualizacion":    1
  }
).sort({ "fecha_actualizacion": -1 });
```

### Q-08. Estudiantes en ALTO riesgo que aún no tienen sesión de tutoría registrada

**Propósito:** Detecta situaciones donde se generó la alerta pero el tutor aún no ha registrado una sesión de acompañamiento, para activar un recordatorio (RF-20, RF-21).

```javascript
// Q-08: Estudiantes en ALTO riesgo sin sesión de tutoría en MongoDB
// (cruzando seguimiento_riesgo con sesiones_tutoria mediante $lookup)
db.seguimiento_riesgo.aggregate([
  {
    $match: {
      "indicador.nivel_riesgo": "ALTO"
    }
  },
  {
    $lookup: {
      from:         "sesiones_tutoria",
      localField:   "estudiante.estudiante_id",
      foreignField: "estudiante.estudiante_id",
      as:           "tutorias_del_estudiante"
    }
  },
  {
    $addFields: {
      tiene_tutoria_registrada: {
        $gt: [{ $size: "$tutorias_del_estudiante" }, 0]
      }
    }
  },
  {
    $match: {
      tiene_tutoria_registrada: false
    }
  },
  {
    $project: {
      _id: 0,
      "estudiante.codigo":               1,
      "estudiante.nombres":              1,
      "estudiante.apellidos":            1,
      "seccion.curso_codigo":            1,
      "indicador.nota_promedio_parcial": 1,
      "indicador.porcentaje_asistencia": 1,
      "indicador.nivel_riesgo":          1,
      alertas:                           1
    }
  }
]);
```

### Q-09. Actualizar el indicador de riesgo de un estudiante y añadir una nueva asistencia al historial

**Propósito:** Demuestra la operación de actualización del documento de seguimiento cuando se registra una nueva asistencia en SQL Server y se sincroniza con MongoDB (RF-18, RF-19).

```javascript
// Q-09: Actualizar seguimiento_riesgo al registrar nueva asistencia
// Escenario: Rodrigo Silva (matricula_id=2) asistió a la sesión del 2026-10-28

db.seguimiento_riesgo.updateOne(
  { "matricula_id": 2 },
  [
    {
      $set: {
        // Añadir la nueva asistencia al inicio del historial (máx. 10)
        "historial_asistencia_reciente": {
          $slice: [
            {
              $concatArrays: [
                [{ fecha_sesion: new Date("2026-10-28"), estado: "PRESENTE" }],
                "$historial_asistencia_reciente"
              ]
            },
            10
          ]
        },
        // Recalcular porcentaje de asistencia (simplificado con +1 sesión presente)
        "indicador.porcentaje_asistencia": {
          $round: [
            {
              $multiply: [
                {
                  $divide: [
                    {
                      $add: [
                        { $multiply: [
                          { $divide: ["$indicador.porcentaje_asistencia", 100] },
                          6
                        ]},
                        1
                      ]
                    },
                    7
                  ]
                },
                100
              ]
            },
            2
          ]
        },
        // Recalcular nivel de riesgo
        "indicador.nivel_riesgo": {
          $switch: {
            branches: [
              {
                case: {
                  $and: [
                    { $lt: ["$indicador.nota_promedio_parcial", 10.5] },
                    { $lt: ["$indicador.porcentaje_asistencia", 70] }
                  ]
                },
                then: "ALTO"
              },
              {
                case: {
                  $or: [
                    { $lt: ["$indicador.nota_promedio_parcial", 10.5] },
                    { $lt: ["$indicador.porcentaje_asistencia", 70] }
                  ]
                },
                then: "MEDIO"
              }
            ],
            default: "BAJO"
          }
        },
        "indicador.fecha_calculo": new Date(),
        "fecha_actualizacion":     new Date()
      }
    }
  ]
);

// Verificar el resultado
db.seguimiento_riesgo.findOne(
  { "matricula_id": 2 },
  { "indicador": 1, "historial_asistencia_reciente": 1, _id: 0 }
);
```
