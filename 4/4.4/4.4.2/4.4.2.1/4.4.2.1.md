# 4.4.2.1. Consultas No Relacionales: Módulo 1 (EUSTAQUIO) — Estructura académica

Las siguientes tres consultas fueron desarrolladas en **MQL** sobre la base de datos `ruta_academica` en **MongoDB 7.0** por **Eustaquio**, cubriendo las necesidades del **Módulo 1: Estructura académica**.

---

### Q-01. Listar todas las asignaciones de tutoría vigentes en un ciclo, agrupadas por tutor

**Propósito:** Permite a la gestión académica ver cuántos estudiantes tiene asignados cada tutor en el ciclo activo, para balancear la carga de tutoría (RF-21).

```javascript
// Q-01: Tutores con sus estudiantes asignados en el ciclo 2026-2
db.sesiones_tutoria.aggregate([
  {
    $match: {
      "ciclo_academico.periodo": "2026-2",
      "estado_asignacion": "VIGENTE"
    }
  },
  {
    $group: {
      _id: {
        docente_id: "$tutor.docente_id",
        tutor:      { $concat: ["$tutor.nombres", " ", "$tutor.apellidos"] }
      },
      total_estudiantes_asignados: { $sum: 1 },
      total_sesiones_realizadas:   { $sum: "$total_sesiones" },
      estudiantes: {
        $push: {
          codigo:          "$estudiante.codigo",
          nombre:          { $concat: ["$estudiante.nombres", " ", "$estudiante.apellidos"] },
          estado_academico:"$estudiante.estado_academico",
          sesiones:        "$total_sesiones",
          ultima_sesion:   "$fecha_ultima_sesion"
        }
      }
    }
  },
  {
    $project: {
      _id: 0,
      tutor:                       "$_id.tutor",
      total_estudiantes_asignados: 1,
      total_sesiones_realizadas:   1,
      estudiantes:                 1
    }
  },
  { $sort: { total_estudiantes_asignados: -1 } }
]);
```

**Resultado esperado:** Documentos con el nombre del tutor, número de estudiantes asignados, total de sesiones realizadas y la lista de estudiantes con su estado académico.

### Q-02. Buscar estudiantes con estado académico REPITENCIA_2 o REPITENCIA_3 que tienen sesiones de tutoría

**Propósito:** Verifica que los estudiantes con repitencia obligatoria (RN-06, RN-12) efectivamente tienen asignación y sesiones de tutoría registradas en MongoDB.

```javascript
// Q-02: Estudiantes en repitencia con tutoría registrada
db.sesiones_tutoria.find(
  {
    "estudiante.estado_academico": {
      $in: ["REPITENCIA_2", "REPITENCIA_3"]
    },
    "estado_asignacion": "VIGENTE",
    "total_sesiones":    { $gte: 1 }
  },
  {
    _id: 0,
    "estudiante.codigo":          1,
    "estudiante.nombres":         1,
    "estudiante.apellidos":       1,
    "estudiante.estado_academico":1,
    "tutor.nombres":              1,
    "tutor.apellidos":            1,
    "total_sesiones":             1,
    "fecha_ultima_sesion":        1,
    "ciclo_academico.periodo":    1
  }
).sort({ "fecha_ultima_sesion": -1 });
```

### Q-03. Sesiones de tutoría realizadas en los últimos 30 días, con sus compromisos

**Propósito:** Permite al coordinador académico revisar las sesiones recientes y verificar que se están registrando compromisos concretos (RF-21).

```javascript
// Q-03: Sesiones de tutoría en los últimos 30 días
const hace30Dias = new Date();
hace30Dias.setDate(hace30Dias.getDate() - 30);

db.sesiones_tutoria.aggregate([
  { $unwind: "$sesiones" },
  {
    $match: {
      "sesiones.fecha": { $gte: hace30Dias }
    }
  },
  {
    $project: {
      _id: 0,
      tutor:        { $concat: ["$tutor.nombres", " ", "$tutor.apellidos"] },
      estudiante:   { $concat: ["$estudiante.nombres", " ", "$estudiante.apellidos"] },
      estado_academico: "$estudiante.estado_academico",
      fecha_sesion:     "$sesiones.fecha",
      duracion_minutos: "$sesiones.duracion_minutos",
      temas_tratados:   "$sesiones.temas_tratados",
      compromisos:      "$sesiones.compromisos",
      tiene_compromisos: {
        $cond: [
          { $and: [
            { $ne: ["$sesiones.compromisos", null] },
            { $ne: ["$sesiones.compromisos", ""] }
          ]},
          true, false
        ]
      }
    }
  },
  { $sort: { "fecha_sesion": -1 } }
]);
```
