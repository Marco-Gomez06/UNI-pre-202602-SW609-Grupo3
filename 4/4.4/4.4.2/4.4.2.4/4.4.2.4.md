# 4.4.2.4. Consultas No Relacionales: Módulo 4 (PAUCAR) — Evaluación, asistencia y riesgo

Las siguientes tres consultas fueron desarrolladas en **MQL** sobre la base de datos `ruta_academica` en **MongoDB 7.0** por **Paucar**, cubriendo las necesidades del **Módulo 4: Evaluación, asistencia y riesgo**.

---

### Q-10. Distribución de niveles de riesgo en el ciclo actual (estadística global)

**Propósito:** Proporciona a la dirección académica una vista ejecutiva de cuántos estudiantes se encuentran en cada nivel de riesgo en el ciclo activo (RF-19, RF-22).

```javascript
// Q-10: Distribución de riesgo en el ciclo 2026-2
db.seguimiento_riesgo.aggregate([
  {
    $match: { "ciclo.periodo": "2026-2" }
  },
  {
    $group: {
      _id: "$indicador.nivel_riesgo",
      cantidad: { $sum: 1 },
      nota_promedio: { $avg: "$indicador.nota_promedio_parcial" },
      asistencia_promedio: { $avg: "$indicador.porcentaje_asistencia" },
      estudiantes: {
        $push: {
          codigo:    "$estudiante.codigo",
          apellidos: "$estudiante.apellidos"
        }
      }
    }
  },
  {
    $project: {
      _id: 0,
      nivel_riesgo:        "$_id",
      cantidad:            1,
      nota_promedio:       { $round: ["$nota_promedio", 2] },
      asistencia_promedio: { $round: ["$asistencia_promedio", 2] },
      estudiantes:         1
    }
  },
  {
    $sort: {
      nivel_riesgo: 1
    }
  }
]);
```

### Q-11. Añadir una nueva sesión de tutoría a un documento existente

**Propósito:** Registra una nueva sesión de tutoría en el documento de la asignación correspondiente, actualiza el contador y la fecha de última sesión (RF-21).

```javascript
// Q-11: Registrar segunda sesión de tutoría para asignacion_tutor_id=1 (Ramírez → Rodrigo)
db.sesiones_tutoria.updateOne(
  { "asignacion_tutor_id": 1 },
  {
    $push: {
      sesiones: {
        sesion_tutoria_id: 4,
        fecha: new Date("2026-10-29T12:00:00"),
        duracion_minutos: 60,
        temas_tratados: "Seguimiento de compromisos; repaso de SQL avanzado y subconsultas.",
        compromisos: "Rodrigo entregará los tres laboratorios pendientes antes del viernes. Próxima sesión: 2026-11-05."
      }
    },
    $inc: { total_sesiones: 1 },
    $set: { fecha_ultima_sesion: new Date("2026-10-29T12:00:00") }
  }
);

// Verificar el resultado
db.sesiones_tutoria.findOne(
  { "asignacion_tutor_id": 1 },
  { "sesiones": 1, "total_sesiones": 1, "fecha_ultima_sesion": 1, _id: 0 }
);
```

### Q-12. Marcar una alerta como atendida y registrar la acción del tutor

**Propósito:** Actualiza el estado de una alerta activa a "ATENDIDA" una vez que el tutor ha tenido la sesión con el estudiante, cerrando el ciclo de seguimiento (RF-20, RF-21).

```javascript
// Q-12: Marcar alerta de Rodrigo Silva (alerta_riesgo_id=1) como ATENDIDA
db.seguimiento_riesgo.updateOne(
  {
    "matricula_id": 2,
    "alertas": {
      $elemMatch: {
        alerta_riesgo_id: 1,
        estado: "ACTIVA"
      }
    }
  },
  {
    $set: {
      "alertas.$.estado":           "ATENDIDA",
      "fecha_actualizacion":        new Date()
    }
  }
);

// Verificar el resultado
db.seguimiento_riesgo.findOne(
  { "matricula_id": 2 },
  { "alertas": 1, "fecha_actualizacion": 1, _id: 0 }
);
```
