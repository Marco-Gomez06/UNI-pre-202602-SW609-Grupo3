# 4.4.2. Consultas para la base de datos no relacional

Las consultas siguientes se implementaron en **MQL (MongoDB Query Language)** sobre la base de datos `ruta_academica` en MongoDB 7.0. Cada integrante implementa tres consultas orientadas a los requisitos del sistema. Las consultas utilizan las colecciones `sesiones_tutoria` y `seguimiento_riesgo` definidas en las secciones 4.2.2 y 4.3.2.

---

## Módulo 1 — Estructura académica (Responsable: Eustaquio)

### Q-01. Listar todas las asignaciones de tutoría vigentes en un ciclo, agrupadas por tutor

**Propósito:** Permite a la gestión académica ver cuántos estudiantes tiene asignados cada tutor en el ciclo activo, para balancear la carga de tutoría (RF-21).

```javascript
// Q-01: Tutores con sus estudiantes asignados en el ciclo 2026-2
db.sesiones_tutoria.aggregate([
  {
    $match: {
      "ciclo_academico.periodo": "2026-2",
      "estado_asignacion": "VIGENTE"
    }
  },
  {
    $group: {
      _id: {
        docente_id: "$tutor.docente_id",
        tutor:      { $concat: ["$tutor.nombres", " ", "$tutor.apellidos"] }
      },
      total_estudiantes_asignados: { $sum: 1 },
      total_sesiones_realizadas:   { $sum: "$total_sesiones" },
      estudiantes: {
        $push: {
          codigo:          "$estudiante.codigo",
          nombre:          { $concat: ["$estudiante.nombres", " ", "$estudiante.apellidos"] },
          estado_academico:"$estudiante.estado_academico",
          sesiones:        "$total_sesiones",
          ultima_sesion:   "$fecha_ultima_sesion"
        }
      }
    }
  },
  {
    $project: {
      _id: 0,
      tutor:                       "$_id.tutor",
      total_estudiantes_asignados: 1,
      total_sesiones_realizadas:   1,
      estudiantes:                 1
    }
  },
  { $sort: { total_estudiantes_asignados: -1 } }
]);
```

**Resultado esperado:** Documentos con el nombre del tutor, número de estudiantes asignados, total de sesiones realizadas y la lista de estudiantes con su estado académico.

### Q-02. Buscar estudiantes con estado académico REPITENCIA_2 o REPITENCIA_3 que tienen sesiones de tutoría

**Propósito:** Verifica que los estudiantes con repitencia obligatoria (RN-06, RN-12) efectivamente tienen asignación y sesiones de tutoría registradas en MongoDB.

```javascript
// Q-02: Estudiantes en repitencia con tutoría registrada
db.sesiones_tutoria.find(
  {
    "estudiante.estado_academico": {
      $in: ["REPITENCIA_2", "REPITENCIA_3"]
    },
    "estado_asignacion": "VIGENTE",
    "total_sesiones":    { $gte: 1 }
  },
  {
    _id: 0,
    "estudiante.codigo":          1,
    "estudiante.nombres":         1,
    "estudiante.apellidos":       1,
    "estudiante.estado_academico":1,
    "tutor.nombres":              1,
    "tutor.apellidos":            1,
    "total_sesiones":             1,
    "fecha_ultima_sesion":        1,
    "ciclo_academico.periodo":    1
  }
).sort({ "fecha_ultima_sesion": -1 });
```

### Q-03. Sesiones de tutoría realizadas en los últimos 30 días, con sus compromisos

**Propósito:** Permite al coordinador académico revisar las sesiones recientes y verificar que se están registrando compromisos concretos (RF-21).

```javascript
// Q-03: Sesiones de tutoría en los últimos 30 días
const hace30Dias = new Date();
hace30Dias.setDate(hace30Dias.getDate() - 30);

db.sesiones_tutoria.aggregate([
  { $unwind: "$sesiones" },
  {
    $match: {
      "sesiones.fecha": { $gte: hace30Dias }
    }
  },
  {
    $project: {
      _id: 0,
      tutor:        { $concat: ["$tutor.nombres", " ", "$tutor.apellidos"] },
      estudiante:   { $concat: ["$estudiante.nombres", " ", "$estudiante.apellidos"] },
      estado_academico: "$estudiante.estado_academico",
      fecha_sesion:     "$sesiones.fecha",
      duracion_minutos: "$sesiones.duracion_minutos",
      temas_tratados:   "$sesiones.temas_tratados",
      compromisos:      "$sesiones.compromisos",
      tiene_compromisos: {
        $cond: [
          { $and: [
            { $ne: ["$sesiones.compromisos", null] },
            { $ne: ["$sesiones.compromisos", ""] }
          ]},
          true, false
        ]
      }
    }
  },
  { $sort: { "fecha_sesion": -1 } }
]);
```

## Módulo 2 — Docentes, secciones y aulas (Responsable: Gomez)

### Q-04. Panel de riesgo de una sección: estudiantes ordenados por nivel de riesgo

**Propósito:** Proporciona al docente el panel de seguimiento de su sección, mostrando nota parcial, asistencia y alertas activas (RF-22). Equivale en MongoDB al panel que en SQL Server requiere múltiples joins.

```javascript
// Q-04: Panel de riesgo de la sección SW609-A (seccion_id=1)
db.seguimiento_riesgo.aggregate([
  {
    $match: { "seccion.seccion_id": 1 }
  },
  {
    $addFields: {
      nivel_riesgo_orden: {
        $switch: {
          branches: [
            { case: { $eq: ["$indicador.nivel_riesgo", "ALTO"] },  then: 1 },
            { case: { $eq: ["$indicador.nivel_riesgo", "MEDIO"] }, then: 2 },
            { case: { $eq: ["$indicador.nivel_riesgo", "BAJO"] },  then: 3 }
          ],
          default: 4
        }
      },
      alertas_activas: {
        $size: {
          $filter: {
            input: "$alertas",
            as:    "a",
            cond:  { $eq: ["$$a.estado", "ACTIVA"] }
          }
        }
      }
    }
  },
  {
    $project: {
      _id: 0,
      "estudiante.codigo":               1,
      "estudiante.nombres":              1,
      "estudiante.apellidos":            1,
      "indicador.nota_promedio_parcial": 1,
      "indicador.porcentaje_asistencia": 1,
      "indicador.nivel_riesgo":          1,
      "indicador.fecha_calculo":         1,
      alertas_activas:                   1,
      numero_matricula_curso:            1,
      nivel_riesgo_orden:                1
    }
  },
  { $sort: { nivel_riesgo_orden: 1, "indicador.nota_promedio_parcial": 1 } }
]);
```

### Q-05. Conteo de estudiantes por nivel de riesgo en cada sección

**Propósito:** Permite a la gestión académica ver un resumen ejecutivo del riesgo académico por sección para priorizar las intervenciones (RF-19, RF-22).

```javascript
// Q-05: Resumen de riesgo por sección
db.seguimiento_riesgo.aggregate([
  {
    $group: {
      _id: {
        seccion_id:        "$seccion.seccion_id",
        curso_codigo:      "$seccion.curso_codigo",
        curso_nombre:      "$seccion.curso_nombre",
        codigo_seccion:    "$seccion.codigo_seccion",
        docente_nombres:   "$seccion.docente_nombres",
        docente_apellidos: "$seccion.docente_apellidos",
        periodo:           "$ciclo.periodo"
      },
      total_estudiantes:  { $sum: 1 },
      riesgo_alto:  { $sum: { $cond: [{ $eq: ["$indicador.nivel_riesgo", "ALTO"] },  1, 0] } },
      riesgo_medio: { $sum: { $cond: [{ $eq: ["$indicador.nivel_riesgo", "MEDIO"] }, 1, 0] } },
      riesgo_bajo:  { $sum: { $cond: [{ $eq: ["$indicador.nivel_riesgo", "BAJO"] },  1, 0] } },
      nota_promedio_seccion: { $avg: "$indicador.nota_promedio_parcial" },
      asist_promedio_seccion: { $avg: "$indicador.porcentaje_asistencia" }
    }
  },
  {
    $project: {
      _id: 0,
      periodo:           "$_id.periodo",
      curso:             { $concat: ["$_id.curso_codigo", " — ", "$_id.curso_nombre"] },
      seccion:           "$_id.codigo_seccion",
      docente:           { $concat: ["$_id.docente_nombres", " ", "$_id.docente_apellidos"] },
      total_estudiantes: 1,
      riesgo_alto:       1,
      riesgo_medio:      1,
      riesgo_bajo:       1,
      nota_promedio_seccion:  { $round: ["$nota_promedio_seccion",  2] },
      asist_promedio_seccion: { $round: ["$asist_promedio_seccion", 2] }
    }
  },
  { $sort: { riesgo_alto: -1 } }
]);
```

### Q-06. Alertas activas con detalle de historial de asistencia reciente

**Propósito:** Permite al tutor revisar el historial de asistencia de los últimos 10 registros de un estudiante en alerta, para contextualizar la situación antes de la sesión de tutoría (RF-20, RF-22).

```javascript
// Q-06: Estudiantes con alerta activa y su historial de asistencia reciente
db.seguimiento_riesgo.aggregate([
  {
    $match: {
      alertas: {
        $elemMatch: { estado: "ACTIVA" }
      }
    }
  },
  {
    $project: {
      _id: 0,
      "estudiante.codigo":    1,
      "estudiante.nombres":   1,
      "estudiante.apellidos": 1,
      "seccion.curso_codigo": 1,
      "seccion.codigo_seccion": 1,
      "indicador":            1,
      alertas_activas: {
        $filter: {
          input: "$alertas",
          as:    "a",
          cond:  { $eq: ["$$a.estado", "ACTIVA"] }
        }
      },
      historial_asistencia_reciente: 1,
      ausencias_recientes: {
        $size: {
          $filter: {
            input: "$historial_asistencia_reciente",
            as:    "h",
            cond:  { $eq: ["$$h.estado", "AUSENTE"] }
          }
        }
      }
    }
  },
  { $sort: { "indicador.nivel_riesgo": 1 } }
]);
```

### Q-08. Estudiantes en ALTO riesgo que aún no tienen sesión de tutoría registrada

**Propósito:** Detecta situaciones donde se generó la alerta pero el tutor aún no ha registrado una sesión de acompañamiento, para activar un recordatorio (RF-20, RF-21).

```javascript
// Q-08: Estudiantes en ALTO riesgo sin sesión de tutoría en MongoDB
// (cruzando seguimiento_riesgo con sesiones_tutoria mediante $lookup)
db.seguimiento_riesgo.aggregate([
  {
    $match: {
      "indicador.nivel_riesgo": "ALTO"
    }
  },
  {
    $lookup: {
      from:         "sesiones_tutoria",
      localField:   "estudiante.estudiante_id",
      foreignField: "estudiante.estudiante_id",
      as:           "tutorias_del_estudiante"
    }
  },
  {
    $addFields: {
      tiene_tutoria_registrada: {
        $gt: [{ $size: "$tutorias_del_estudiante" }, 0]
      }
    }
  },
  {
    $match: {
      tiene_tutoria_registrada: false
    }
  },
  {
    $project: {
      _id: 0,
      "estudiante.codigo":               1,
      "estudiante.nombres":              1,
      "estudiante.apellidos":            1,
      "seccion.curso_codigo":            1,
      "indicador.nota_promedio_parcial": 1,
      "indicador.porcentaje_asistencia": 1,
      "indicador.nivel_riesgo":          1,
      alertas:                           1
    }
  }
]);
```

### Q-09. Actualizar el indicador de riesgo de un estudiante y añadir una nueva asistencia al historial

**Propósito:** Demuestra la operación de actualización del documento de seguimiento cuando se registra una nueva asistencia en SQL Server y se sincroniza con MongoDB (RF-18, RF-19).

```javascript
// Q-09: Actualizar seguimiento_riesgo al registrar nueva asistencia
// Escenario: Rodrigo Silva (matricula_id=2) asistió a la sesión del 2026-10-28

db.seguimiento_riesgo.updateOne(
  { "matricula_id": 2 },
  [
    {
      $set: {
        // Añadir la nueva asistencia al inicio del historial (máx. 10)
        "historial_asistencia_reciente": {
          $slice: [
            {
              $concatArrays: [
                [{ fecha_sesion: new Date("2026-10-28"), estado: "PRESENTE" }],
                "$historial_asistencia_reciente"
              ]
            },
            10
          ]
        },
        // Recalcular porcentaje de asistencia (simplificado con +1 sesión presente)
        "indicador.porcentaje_asistencia": {
          $round: [
            {
              $multiply: [
                {
                  $divide: [
                    {
                      $add: [
                        { $multiply: [
                          { $divide: ["$indicador.porcentaje_asistencia", 100] },
                          6
                        ]},
                        1
                      ]
                    },
                    7
                  ]
                },
                100
              ]
            },
            2
          ]
        },
        // Recalcular nivel de riesgo
        "indicador.nivel_riesgo": {
          $switch: {
            branches: [
              {
                case: {
                  $and: [
                    { $lt: ["$indicador.nota_promedio_parcial", 10.5] },
                    { $lt: ["$indicador.porcentaje_asistencia", 70] }
                  ]
                },
                then: "ALTO"
              },
              {
                case: {
                  $or: [
                    { $lt: ["$indicador.nota_promedio_parcial", 10.5] },
                    { $lt: ["$indicador.porcentaje_asistencia", 70] }
                  ]
                },
                then: "MEDIO"
              }
            ],
            default: "BAJO"
          }
        },
        "indicador.fecha_calculo": new Date(),
        "fecha_actualizacion":     new Date()
      }
    }
  ]
);

// Verificar el resultado
db.seguimiento_riesgo.findOne(
  { "matricula_id": 2 },
  { "indicador": 1, "historial_asistencia_reciente": 1, _id: 0 }
);
```

## Módulo 4 — Evaluación, asistencia y riesgo (Responsable: Paucar)

### Q-10. Distribución de niveles de riesgo en el ciclo actual (estadística global)

**Propósito:** Proporciona a la dirección académica una vista ejecutiva de cuántos estudiantes se encuentran en cada nivel de riesgo en el ciclo activo (RF-19, RF-22).

```javascript
// Q-10: Distribución de riesgo en el ciclo 2026-2
db.seguimiento_riesgo.aggregate([
  {
    $match: { "ciclo.periodo": "2026-2" }
  },
  {
    $group: {
      _id: "$indicador.nivel_riesgo",
      cantidad: { $sum: 1 },
      nota_promedio: { $avg: "$indicador.nota_promedio_parcial" },
      asistencia_promedio: { $avg: "$indicador.porcentaje_asistencia" },
      estudiantes: {
        $push: {
          codigo:    "$estudiante.codigo",
          apellidos: "$estudiante.apellidos"
        }
      }
    }
  },
  {
    $project: {
      _id: 0,
      nivel_riesgo:        "$_id",
      cantidad:            1,
      nota_promedio:       { $round: ["$nota_promedio", 2] },
      asistencia_promedio: { $round: ["$asistencia_promedio", 2] },
      estudiantes:         1
    }
  },
  {
    $sort: {
      nivel_riesgo: 1
    }
  }
]);
```

### Q-11. Añadir una nueva sesión de tutoría a un documento existente

**Propósito:** Registra una nueva sesión de tutoría en el documento de la asignación correspondiente, actualiza el contador y la fecha de última sesión (RF-21).

```javascript
// Q-11: Registrar segunda sesión de tutoría para asignacion_tutor_id=1 (Ramírez → Rodrigo)
db.sesiones_tutoria.updateOne(
  { "asignacion_tutor_id": 1 },
  {
    $push: {
      sesiones: {
        sesion_tutoria_id: 4,
        fecha: new Date("2026-10-29T12:00:00"),
        duracion_minutos: 60,
        temas_tratados: "Seguimiento de compromisos; repaso de SQL avanzado y subconsultas.",
        compromisos: "Rodrigo entregará los tres laboratorios pendientes antes del viernes. Próxima sesión: 2026-11-05."
      }
    },
    $inc: { total_sesiones: 1 },
    $set: { fecha_ultima_sesion: new Date("2026-10-29T12:00:00") }
  }
);

// Verificar el resultado
db.sesiones_tutoria.findOne(
  { "asignacion_tutor_id": 1 },
  { "sesiones": 1, "total_sesiones": 1, "fecha_ultima_sesion": 1, _id: 0 }
);
```

### Q-12. Marcar una alerta como atendida y registrar la acción del tutor

**Propósito:** Actualiza el estado de una alerta activa a "ATENDIDA" una vez que el tutor ha tenido la sesión con el estudiante, cerrando el ciclo de seguimiento (RF-20, RF-21).

```javascript
// Q-12: Marcar alerta de Rodrigo Silva (alerta_riesgo_id=1) como ATENDIDA
db.seguimiento_riesgo.updateOne(
  {
    "matricula_id": 2,
    "alertas": {
      $elemMatch: {
        alerta_riesgo_id: 1,
        estado: "ACTIVA"
      }
    }
  },
  {
    $set: {
      "alertas.$.estado":           "ATENDIDA",
      "fecha_actualizacion":        new Date()
    }
  }
);

// Verificar
db.seguimiento_riesgo.findOne(
  { "matricula_id": 2 },
  { "alertas": 1, "fecha_actualizacion": 1, _id: 0 }
);
```
