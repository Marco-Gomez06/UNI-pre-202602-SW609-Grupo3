# 4.4.1.1. Consultas Relacionales: Módulo 1 (EUSTAQUIO) — Estructura académica

Las siguientes cinco consultas fueron desarrolladas en **T-SQL** para Microsoft SQL Server 2022 por **Eustaquio**, cubriendo las necesidades del **Módulo 1: Estructura académica**.

---

### C-01. Listar cursos de un plan de estudios con su ciclo sugerido y prerrequisitos

**Propósito:** Permite a gestión académica visualizar la malla completa de una carrera, incluyendo el ciclo recomendado y los prerrequisitos de cada curso (RF-02).

```sql
-- C-01: Malla curricular con prerrequisitos
SELECT
    pc.ciclo_sugerido,
    c.codigo                    AS curso_codigo,
    c.nombre                    AS curso_nombre,
    c.creditos,
    CASE pc.es_obligatorio
        WHEN 1 THEN 'Obligatorio'
        ELSE 'Electivo'
    END                         AS tipo,
    ISNULL(cr.codigo, '—')      AS prereq_codigo,
    ISNULL(cr.nombre, '—')      AS prereq_nombre
FROM plan_curso pc
    INNER JOIN plan_estudio pe  ON pe.plan_estudio_id = pc.plan_estudio_id
    INNER JOIN curso c          ON c.curso_id         = pc.curso_id
    LEFT  JOIN prerrequisito pr ON pr.curso_id        = c.curso_id
    LEFT  JOIN curso cr         ON cr.curso_id        = pr.curso_requisito_id
WHERE pe.nombre_carrera = 'Ingeniería de Software'
  AND pe.estado         = 'ACTIVO'
ORDER BY pc.ciclo_sugerido, c.nombre;
```

### C-02. Consultar secciones abiertas por curso y ciclo con disponibilidad de vacantes

**Propósito:** Permite al estudiante verificar las secciones disponibles antes de su turno (RF-11).

```sql
-- C-02: Disponibilidad de vacantes por curso y ciclo
SELECT
    c.codigo                                        AS curso_codigo,
    c.nombre                                        AS curso_nombre,
    s.codigo_seccion,
    d.nombres + ' ' + d.apellidos                   AS docente,
    a.codigo                                        AS aula,
    s.vacantes_disponibles,
    s.vacantes_totales,
    s.modalidad,
    STRING_AGG(
        CASE hs.dia_semana
            WHEN 1 THEN 'Lun' WHEN 2 THEN 'Mar' WHEN 3 THEN 'Mie'
            WHEN 4 THEN 'Jue' WHEN 5 THEN 'Vie' WHEN 6 THEN 'Sab'
        END + ' ' +
        FORMAT(CAST(hs.hora_inicio AS DATETIME), 'HH:mm') + '-' +
        FORMAT(CAST(hs.hora_fin    AS DATETIME), 'HH:mm'),
        ' | '
    ) WITHIN GROUP (ORDER BY hs.dia_semana, hs.hora_inicio) AS horario
FROM seccion s
    INNER JOIN curso c              ON c.curso_id            = s.curso_id
    INNER JOIN ciclo_academico ca   ON ca.ciclo_academico_id = s.ciclo_academico_id
    INNER JOIN docente d            ON d.docente_id          = s.docente_id
    INNER JOIN aula a               ON a.aula_id             = s.aula_id
    LEFT  JOIN horario_seccion hs   ON hs.seccion_id         = s.seccion_id
WHERE ca.periodo = '2026-2'
  AND c.codigo   = 'SW609'
GROUP BY
    c.codigo, c.nombre, s.codigo_seccion,
    d.nombres, d.apellidos, a.codigo,
    s.vacantes_disponibles, s.vacantes_totales, s.modalidad
ORDER BY s.vacantes_disponibles DESC;
```

### C-03. Turnos de matrícula vigentes con rango de promedio y tope de créditos

**Propósito:** Permite al estudiante conocer en qué turno le corresponde matricularse (RF-04).

```sql
-- C-03: Turnos de matrícula del ciclo activo
SELECT
    ca.periodo,
    tm.numero_turno,
    tm.promedio_minimo,
    tm.promedio_maximo,
    tm.tope_creditos,
    FORMAT(tm.fecha_hora_inicio, 'dd/MM/yyyy HH:mm') AS inicio_turno,
    FORMAT(tm.fecha_hora_fin,    'dd/MM/yyyy HH:mm') AS fin_turno
FROM turno_matricula tm
    INNER JOIN ciclo_academico ca ON ca.ciclo_academico_id = tm.ciclo_academico_id
WHERE ca.estado = 'ACTIVO'
ORDER BY tm.numero_turno;
```

### C-04. Resumen de demanda insatisfecha por sección (para planificación de oferta)

**Propósito:** Permite a la Comisión de Matrícula identificar las secciones con mayor demanda no atendida antes del cierre del proceso (RF-09).

```sql
-- C-04: Demanda insatisfecha agrupada por sección y curso
SELECT
    ca.periodo,
    c.codigo                        AS curso_codigo,
    c.nombre                        AS curso_nombre,
    s.codigo_seccion,
    di.motivo,
    COUNT(*)                        AS intentos_fallidos,
    s.vacantes_totales,
    s.vacantes_disponibles
FROM demanda_insatisfecha di
    INNER JOIN seccion s            ON s.seccion_id          = di.seccion_id
    INNER JOIN curso c              ON c.curso_id            = s.curso_id
    INNER JOIN ciclo_academico ca   ON ca.ciclo_academico_id = s.ciclo_academico_id
WHERE ca.periodo = '2026-2'
GROUP BY
    ca.periodo, c.codigo, c.nombre, s.codigo_seccion,
    di.motivo, s.vacantes_totales, s.vacantes_disponibles
ORDER BY intentos_fallidos DESC;
```

### C-05. Validar si un estudiante cumple prerrequisitos para un curso

**Propósito:** Verifica de forma automática si el estudiante puede matricularse en un curso, revisando que haya aprobado todos sus prerrequisitos (RF-13, RN-03). Se presenta como procedimiento almacenado.

```sql
-- C-05: Procedimiento para validar prerrequisitos
CREATE OR ALTER PROCEDURE sp_validar_prerrequisitos
    @estudiante_id  INT,
    @curso_id       INT,
    @puede_matricular BIT OUTPUT,
    @mensaje          VARCHAR(500) OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @prereqs_pendientes INT;

    -- Contar prerrequisitos no aprobados
    SELECT @prereqs_pendientes = COUNT(*)
    FROM prerrequisito pr
    WHERE pr.curso_id = @curso_id
      AND NOT EXISTS (
          SELECT 1
          FROM matricula m
              INNER JOIN seccion sec ON sec.seccion_id = m.seccion_id
          WHERE m.estudiante_id = @estudiante_id
            AND sec.curso_id    = pr.curso_requisito_id
            AND m.estado        = 'APROBADO'
      );

    IF @prereqs_pendientes = 0
    BEGIN
        SET @puede_matricular = 1;
        SET @mensaje = 'El estudiante cumple todos los prerrequisitos.';
    END
    ELSE
    BEGIN
        SET @puede_matricular = 0;
        SET @mensaje = CONCAT(
            'El estudiante tiene ', @prereqs_pendientes,
            ' prerrequisito(s) pendiente(s) para este curso.'
        );
    END;
END;
GO

-- Ejemplo de ejecución
DECLARE @puede BIT, @msg VARCHAR(500);
EXEC sp_validar_prerrequisitos
    @estudiante_id    = 1,
    @curso_id         = 1,
    @puede_matricular = @puede OUTPUT,
    @mensaje          = @msg   OUTPUT;
SELECT @puede AS puede_matricular, @msg AS mensaje;
GO
```
