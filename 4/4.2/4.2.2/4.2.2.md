# 4.2.2. Diagrama de documentos

El diagrama de documentos representa la estructura de los documentos almacenados en la base de datos no relacional `ruta_academica` implementada en **MongoDB 7.0**. Se presenta la estructura de cada colección mediante su JSON Schema y un diagrama en notación de árbol que muestra los campos, tipos y relaciones entre subdocumentos.

Las colecciones fueron identificadas en la sección 3.4.1 y sus validaciones de esquema se definieron en la sección 3.4.2. Los patrones de modelado aplicados se describen en la sección 3.4.3.

---

## Colección `sesiones_tutoria`

**Patrón aplicado:** *Embedded Document Pattern*. Toda la información de una asignación de tutoría —datos del tutor, del estudiante tutorado y el historial de sesiones— se embebe en un único documento. Esto permite recuperar el perfil completo de tutoría de un estudiante en una sola lectura, sin lookups adicionales.

**Propósito:** soportar el RF-21 (registro de sesiones de tutoría) y el RF-22 (panel de riesgo del docente/tutor). La colección es de escritura moderada (una sesión por semana por estudiante en riesgo) y de lectura frecuente (consulta del panel).

### Estructura del documento

```json
{
  "_id": "ObjectId",
  "asignacion_tutor_id": "int (FK referencia SQL Server)",
  "ciclo_academico": {
    "ciclo_academico_id": "int",
    "periodo": "string",
    "fecha_inicio": "date",
    "fecha_fin": "date"
  },
  "tutor": {
    "docente_id": "int",
    "codigo": "string",
    "nombres": "string",
    "apellidos": "string",
    "correo_institucional": "string"
  },
  "estudiante": {
    "estudiante_id": "int",
    "codigo": "string",
    "nombres": "string",
    "apellidos": "string",
    "correo_institucional": "string",
    "plan_estudio": "string",
    "ciclo_actual": "int",
    "estado_academico": "string"
  },
  "fecha_asignacion": "date",
  "estado_asignacion": "string ['VIGENTE', 'FINALIZADA']",
  "sesiones": [
    {
      "sesion_tutoria_id": "int",
      "fecha": "datetime",
      "duracion_minutos": "int",
      "temas_tratados": "string",
      "compromisos": "string | null"
    }
  ],
  "total_sesiones": "int (campo calculado)",
  "fecha_ultima_sesion": "datetime | null"
}
```

### JSON Schema Validation

```javascript
db.createCollection("sesiones_tutoria", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: [
        "asignacion_tutor_id", "ciclo_academico", "tutor",
        "estudiante", "fecha_asignacion", "estado_asignacion",
        "sesiones", "total_sesiones"
      ],
      properties: {
        asignacion_tutor_id: { bsonType: "int", minimum: 1 },
        ciclo_academico: {
          bsonType: "object",
          required: ["ciclo_academico_id", "periodo", "fecha_inicio", "fecha_fin"],
          properties: {
            ciclo_academico_id: { bsonType: "int" },
            periodo: { bsonType: "string", pattern: "^[0-9]{4}-[12]$" },
            fecha_inicio: { bsonType: "date" },
            fecha_fin: { bsonType: "date" }
          }
        },
        tutor: {
          bsonType: "object",
          required: ["docente_id", "codigo", "nombres", "apellidos"],
          properties: {
            docente_id: { bsonType: "int" },
            codigo: { bsonType: "string" },
            nombres: { bsonType: "string" },
            apellidos: { bsonType: "string" },
            correo_institucional: { bsonType: "string" }
          }
        },
        estudiante: {
          bsonType: "object",
          required: ["estudiante_id", "codigo", "nombres", "apellidos", "ciclo_actual", "estado_academico"],
          properties: {
            estudiante_id: { bsonType: "int" },
            codigo: { bsonType: "string" },
            nombres: { bsonType: "string" },
            apellidos: { bsonType: "string" },
            correo_institucional: { bsonType: "string" },
            plan_estudio: { bsonType: "string" },
            ciclo_actual: { bsonType: "int", minimum: 1 },
            estado_academico: {
              bsonType: "string",
              enum: ["REGULAR", "REPITENCIA_2", "REPITENCIA_3", "SEPARADO"]
            }
          }
        },
        fecha_asignacion: { bsonType: "date" },
        estado_asignacion: {
          bsonType: "string",
          enum: ["VIGENTE", "FINALIZADA"]
        },
        sesiones: {
          bsonType: "array",
          items: {
            bsonType: "object",
            required: ["fecha", "duracion_minutos", "temas_tratados"],
            properties: {
              sesion_tutoria_id: { bsonType: "int" },
              fecha: { bsonType: "date" },
              duracion_minutos: { bsonType: "int", minimum: 15 },
              temas_tratados: { bsonType: "string", minLength: 1 },
              compromisos: { bsonType: ["string", "null"] }
            }
          }
        },
        total_sesiones: { bsonType: "int", minimum: 0 },
        fecha_ultima_sesion: { bsonType: ["date", "null"] }
      }
    }
  }
})
```

## Colección `seguimiento_riesgo`

**Patrón aplicado:** *Subset Pattern*. Se almacena solo el subconjunto de información de riesgo que necesita el panel del tutor (RF-22): nota promedio parcial, porcentaje de asistencia, nivel de riesgo e historial reciente de las últimas 10 sesiones de asistencia. Los datos históricos completos se conservan en SQL Server en las tablas `calificacion` y `asistencia`.

**Propósito:** soportar el RF-19 (cálculo de indicadores de riesgo), RF-20 (generación de alertas) y RF-22 (panel de riesgo). La colección se actualiza cada vez que se registra una nota o una asistencia en SQL Server.

  "seccion": {

    "codigo_seccion": "string",
    "docente_nombres": "string",

### JSON Schema Validation

```javascript
db.createCollection("seguimiento_riesgo", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: [
        "matricula_id", "estudiante", "seccion", "ciclo",
        "indicador", "alertas", "historial_asistencia_reciente",
        "numero_matricula_curso", "fecha_actualizacion"
      ],
      properties: {
        matricula_id: { bsonType: "int", minimum: 1 },
        estudiante: {
          bsonType: "object",
          required: ["estudiante_id", "codigo", "nombres", "apellidos"],
          properties: {
            estudiante_id: { bsonType: "int" },
            codigo: { bsonType: "string" },
            nombres: { bsonType: "string" },
            apellidos: { bsonType: "string" }
          }
        },
        seccion: {
          bsonType: "object",
          required: ["seccion_id", "curso_codigo", "curso_nombre", "codigo_seccion"],
          properties: {
            seccion_id: { bsonType: "int" },
            curso_codigo: { bsonType: "string" },
            curso_nombre: { bsonType: "string" },
            codigo_seccion: { bsonType: "string" },
            docente_nombres: { bsonType: "string" },
            docente_apellidos: { bsonType: "string" }
          }
        },
        ciclo: {
          bsonType: "object",
          required: ["ciclo_academico_id", "periodo"],
          properties: {
            ciclo_academico_id: { bsonType: "int" },
            periodo: { bsonType: "string", pattern: "^[0-9]{4}-[12]$" }
          }
        },
        indicador: {
          bsonType: "object",
          required: ["nivel_riesgo", "fecha_calculo"],
          properties: {
            nota_promedio_parcial: { bsonType: ["decimal", "null"] },
            porcentaje_asistencia: { bsonType: ["decimal", "null"] },
            nivel_riesgo: { bsonType: "string", enum: ["BAJO", "MEDIO", "ALTO"] },
            fecha_calculo: { bsonType: "date" }
          }
        },
        alertas: {
          bsonType: "array",
          items: {
            bsonType: "object",
            required: ["motivo", "estado", "fecha_generacion"],
            properties: {
              alerta_riesgo_id: { bsonType: "int" },
              motivo: { bsonType: "string", enum: ["NOTA_BAJA", "INASISTENCIA", "AMBOS"] },
              estado: { bsonType: "string", enum: ["ACTIVA", "ATENDIDA", "DESCARTADA"] },
              fecha_generacion: { bsonType: "date" }
            }
          }
        },
        historial_asistencia_reciente: {
          bsonType: "array",
          maxItems: 10,
          items: {
            bsonType: "object",
            required: ["fecha_sesion", "estado"],
            properties: {
              fecha_sesion: { bsonType: "date" },
              estado: {
                bsonType: "string",
                enum: ["PRESENTE", "AUSENTE", "TARDANZA", "JUSTIFICADO"]
              }
            }
          }
        },
        numero_matricula_curso: { bsonType: "int", minimum: 1, maximum: 4 },
        fecha_actualizacion: { bsonType: "date" }
      }
    }
  }
})
```
