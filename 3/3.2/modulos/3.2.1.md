# 3.2.1. Módulo 1 — Estructura académica

> [3.2. Atributos](../3.2.md) › Módulo 1

Las tablas y atributos siguientes corresponden a la estructura académica.

### `facultad`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `facultad_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la facultad. |
| `codigo` | `VARCHAR(20)` | UQ, NOT NULL | Código oficial de la facultad. Ejemplo: `FIIS`. |
| `nombre` | `VARCHAR(100)` | NOT NULL | Nombre completo de la facultad. |

### `plan_estudio`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `plan_estudio_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del plan de estudios. |
| `facultad_id` | `INT` | FK → `facultad.facultad_id`, NOT NULL | Facultad a la que pertenece la carrera. |
| `nombre_carrera` | `VARCHAR(100)` | NOT NULL | Nombre de la carrera profesional. |
| `total_creditos` | `INT` | NOT NULL | Créditos requeridos para el egreso. |
| `numero_ciclos` | `INT` | NOT NULL | Cantidad de ciclos del plan. |
| `estado` | `VARCHAR(20)` | NOT NULL, `CHECK ('ACTIVO','INACTIVO')` | Estado actual del plan. |

### `curso`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `curso_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del curso. |
| `codigo` | `VARCHAR(20)` | UQ, NOT NULL | Código del curso. Ejemplo: `SW609`. |
| `nombre` | `VARCHAR(100)` | NOT NULL | Nombre del curso. |
| `creditos` | `INT` | NOT NULL | Créditos del curso. |
| `horas_teoria` | `INT` | NOT NULL | Horas semanales de teoría. |
| `horas_practica` | `INT` | NOT NULL | Horas semanales de práctica. |
| `horas_laboratorio` | `INT` | NOT NULL | Horas semanales de laboratorio. |
| `estado` | `VARCHAR(20)` | NOT NULL, `CHECK ('ACTIVO','INACTIVO')` | Estado actual del curso. |

### `plan_curso`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `plan_estudio_id` | `INT` | PK compuesta, FK → `plan_estudio.plan_estudio_id`, NOT NULL | Plan de estudios. |
| `curso_id` | `INT` | PK compuesta, FK → `curso.curso_id`, NOT NULL | Curso incluido en el plan. |
| `ciclo_sugerido` | `INT` | NOT NULL | Ciclo en que el plan recomienda llevar el curso. |
| `es_obligatorio` | `BIT` | NOT NULL | `1` indica obligatorio y `0` indica electivo. |

### `prerrequisito`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `curso_id` | `INT` | PK compuesta, FK → `curso.curso_id`, NOT NULL | Curso que exige el requisito. |
| `curso_requisito_id` | `INT` | PK compuesta, FK → `curso.curso_id`, NOT NULL | Curso que debe estar aprobado. |

Además, se aplica `CHECK (curso_id <> curso_requisito_id)` para impedir que un curso sea requisito de sí mismo.

### `ciclo_academico`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `ciclo_academico_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del ciclo. |
| `periodo` | `VARCHAR(10)` | UQ, NOT NULL | Periodo en formato `AAAA-N`. Ejemplo: `2026-2`. |
| `fecha_inicio` | `DATE` | NOT NULL | Inicio del dictado de clases. |
| `fecha_fin` | `DATE` | NOT NULL | Fin del dictado de clases. |
| `fecha_inicio_matricula` | `DATETIME` | NOT NULL | Apertura del proceso de matrícula. |
| `fecha_fin_matricula` | `DATETIME` | NOT NULL | Cierre del proceso de matrícula. |
| `fecha_inicio_evaluaciones` | `DATE` | NOT NULL | Inicio del periodo de evaluaciones. |
| `fecha_fin_evaluaciones` | `DATE` | NOT NULL | Fin del periodo de evaluaciones. |
| `estado` | `VARCHAR(20)` | NOT NULL, `CHECK ('PLANIFICADO','ACTIVO','CERRADO')` | Estado actual del ciclo. |

### `turno_matricula`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `turno_matricula_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del turno. |
| `ciclo_academico_id` | `INT` | FK → `ciclo_academico.ciclo_academico_id`, NOT NULL | Ciclo al que aplica el turno. |
| `numero_turno` | `INT` | UQ con `ciclo_academico_id`, NOT NULL | Orden del turno dentro del ciclo. |
| `promedio_minimo` | `DECIMAL(4,2)` | NOT NULL | Límite inferior del promedio ponderado. |
| `promedio_maximo` | `DECIMAL(4,2)` | NOT NULL | Límite superior del promedio ponderado. |
| `tope_creditos` | `INT` | NOT NULL | Máximo de créditos permitido. |
| `fecha_hora_inicio` | `DATETIME` | NOT NULL | Inicio de la ventana de matrícula. |
| `fecha_hora_fin` | `DATETIME` | NOT NULL | Fin de la ventana de matrícula. |

La combinación única `(ciclo_academico_id, numero_turno)` impide duplicar turnos dentro de un mismo ciclo académico.
