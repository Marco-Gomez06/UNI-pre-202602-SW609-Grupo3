# 3.2.4. Módulo 4 — Evaluación, asistencia y riesgo

> [3.2. Atributos](../3.2.md) › Módulo 4

Este módulo utiliza los tipos físicos de Microsoft SQL Server.

### `evaluacion`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `evaluacion_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la evaluación. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección evaluada. |
| `nombre` | `VARCHAR(100)` | NOT NULL | Nombre de la evaluación. |
| `fecha` | `DATE` | NOT NULL | Fecha programada. |
| `peso_porcentual` | `DECIMAL(5,2)` | NOT NULL, `CHECK 0 a 100` | Peso sobre la nota final. |

### `calificacion`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `calificacion_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la calificación. |
| `evaluacion_id` | `INT` | FK → `evaluacion.evaluacion_id`, NOT NULL | Evaluación calificada. |
| `matricula_id` | `INT` | FK → `matricula.matricula_id`, NOT NULL | Matrícula calificada. |
| `nota` | `DECIMAL(4,2)` | NOT NULL, `CHECK 0 a 20` | Nota obtenida. |
| `fecha_registro` | `DATETIME` | NOT NULL | Momento del registro. |

La combinación `(evaluacion_id, matricula_id)` debe ser única.

### `sesion_clase`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `sesion_clase_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la sesión. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección a la que pertenece. |
| `fecha` | `DATE` | NOT NULL | Fecha de la sesión. |
| `tema` | `VARCHAR(255)` | NULL | Tema desarrollado. |

### `asistencia`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `asistencia_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la asistencia. |
| `sesion_clase_id` | `INT` | FK → `sesion_clase.sesion_clase_id`, NOT NULL | Sesión correspondiente. |
| `matricula_id` | `INT` | FK → `matricula.matricula_id`, NOT NULL | Matrícula del estudiante. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `PRESENTE`, `AUSENTE`, `TARDANZA`, `JUSTIFICADO` | Estado de asistencia. |

La combinación `(sesion_clase_id, matricula_id)` debe ser única.

### `indicador_riesgo`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `indicador_riesgo_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del indicador. |
| `matricula_id` | `INT` | FK → `matricula.matricula_id`, UQ, NOT NULL | Matrícula evaluada. |
| `nota_promedio_parcial` | `DECIMAL(4,2)` | NULL | Promedio parcial vigente. |
| `porcentaje_asistencia` | `DECIMAL(5,2)` | NULL, `CHECK 0 a 100` | Porcentaje acumulado de asistencia. |
| `nivel_riesgo` | `VARCHAR(20)` | NOT NULL, dominio `BAJO`, `MEDIO`, `ALTO` | Nivel de riesgo actual. |
| `fecha_calculo` | `DATETIME` | NOT NULL | Última actualización del cálculo. |

### `alerta_riesgo`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `alerta_riesgo_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la alerta. |
| `matricula_id` | `INT` | FK → `matricula.matricula_id`, NOT NULL | Matrícula en riesgo. |
| `docente_id` | `INT` | FK → `docente.docente_id`, NULL | Tutor notificado. |
| `fecha_generacion` | `DATETIME` | NOT NULL | Momento de generación. |
| `motivo` | `VARCHAR(30)` | NOT NULL, dominio `NOTA_BAJA`, `INASISTENCIA`, `AMBOS` | Motivo de la alerta. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `ACTIVA`, `ATENDIDA`, `DESCARTADA` | Estado de la alerta. |

### `asignacion_tutor`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `asignacion_tutor_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la asignación. |
| `docente_id` | `INT` | FK → `docente.docente_id`, NOT NULL | Docente tutor. |
| `estudiante_id` | `INT` | FK → `estudiante.estudiante_id`, NOT NULL | Estudiante tutorado. |
| `ciclo_academico_id` | `INT` | FK → `ciclo_academico.ciclo_academico_id`, NOT NULL | Ciclo de la asignación. |
| `fecha_asignacion` | `DATE` | NOT NULL | Fecha de asignación. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `VIGENTE`, `FINALIZADA` | Estado de la asignación. |

La combinación `(estudiante_id, ciclo_academico_id)` debe ser única.

### `sesion_tutoria`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `sesion_tutoria_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la sesión. |
| `asignacion_tutor_id` | `INT` | FK → `asignacion_tutor.asignacion_tutor_id`, NOT NULL | Asignación asociada. |
| `fecha` | `DATETIME` | NOT NULL | Fecha y hora de la sesión. |
| `duracion_minutos` | `INT` | NOT NULL | Duración de la sesión. |
| `temas_tratados` | `VARCHAR(500)` | NOT NULL | Temas abordados. |
| `compromisos` | `VARCHAR(500)` | NULL | Compromisos acordados. |
