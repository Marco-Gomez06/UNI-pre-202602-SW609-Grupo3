# 3.2. Atributos

Un atributo es una característica o propiedad de una entidad. Esta sección describe los atributos de las 27 entidades de la sección 3.1. Los tipos son **lógicos** (independientes del gestor de base de datos); la sección 4.2.1 los traducirá a tipos físicos una vez elegido el sistema de gestión.

**Notación de las tablas**

| Símbolo | Significado |
|---|---|
| **PK** | Clave primaria: identifica de forma única cada registro. |
| **FK → tabla** | Clave foránea: referencia a la clave primaria de otra entidad. |
| **UQ** | Valor único: no puede repetirse entre registros. |
| **Obligatorio / Opcional** | Si el atributo admite o no valores vacíos. |

**Tipos lógicos:** entero, decimal, texto, fecha, hora, fecha-hora y booleano. Los atributos con «Dominio:» solo aceptan los valores listados.
