# 3.2.3. Módulo 3 — Estudiantes y matrícula

> [3.2. Atributos](../3.2.md) › Módulo 3

Este módulo utiliza los tipos físicos de Microsoft SQL Server.

### `estudiante`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `estudiante_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del estudiante. |
| `usuario_id` | `INT` | FK → `usuario.usuario_id`, UQ, NOT NULL | Cuenta de acceso del estudiante. |
| `plan_estudio_id` | `INT` | FK → `plan_estudio.plan_estudio_id`, NOT NULL | Plan de estudios que cursa. |
| `codigo` | `VARCHAR(20)` | UQ, NOT NULL | Código de estudiante. |
| `nombres` | `VARCHAR(100)` | NOT NULL | Nombres del estudiante. |
| `apellidos` | `VARCHAR(100)` | NOT NULL | Apellidos del estudiante. |
| `ciclo_actual` | `INT` | NOT NULL | Ciclo académico actual. |
| `promedio_ponderado` | `DECIMAL(4,2)` | NOT NULL, `CHECK 0 a 20` | Promedio acumulado del estudiante. |
| `estado_academico` | `VARCHAR(30)` | NOT NULL, dominio `REGULAR`, `REPITENCIA_2`, `REPITENCIA_3`, `SEPARADO` | Situación académica vigente. |

### `reserva_vacante`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `reserva_vacante_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la reserva. |
| `estudiante_id` | `INT` | FK → `estudiante.estudiante_id`, NOT NULL | Estudiante que reserva. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección reservada. |
| `fecha_reserva` | `DATETIME` | NOT NULL | Momento de la reserva. |
| `fecha_vencimiento` | `DATETIME` | NOT NULL, `CHECK fecha_vencimiento > fecha_reserva` | Momento en que caduca. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `ACTIVA`, `CONFIRMADA`, `VENCIDA`, `CANCELADA` | Estado de la reserva. |

### `matricula`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `matricula_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la matrícula. |
| `estudiante_id` | `INT` | FK → `estudiante.estudiante_id`, NOT NULL | Estudiante matriculado. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección matriculada. |
| `reserva_vacante_id` | `INT` | FK → `reserva_vacante.reserva_vacante_id`, UQ, NULL | Reserva que originó la matrícula. |
| `usuario_registra_id` | `INT` | FK → `usuario.usuario_id`, NOT NULL | Usuario que ejecutó la operación. |
| `tipo_registro` | `VARCHAR(20)` | NOT NULL, dominio `REGULAR`, `RECTIFICACION` | Tipo de registro. |
| `motivo_rectificacion` | `VARCHAR(255)` | NULL | Justificación de una rectificación. |
| `numero_matricula_curso` | `INT` | NOT NULL, `CHECK 1 a 4` | Veces que el estudiante lleva el curso. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `MATRICULADO`, `RETIRADO`, `APROBADO`, `DESAPROBADO` | Estado de la matrícula. |
| `nota_final` | `DECIMAL(4,2)` | NULL, `CHECK 0 a 20` | Nota final obtenida. |
| `fecha_matricula` | `DATETIME` | NOT NULL | Momento de la confirmación. |

La combinación `(estudiante_id, seccion_id)` debe ser única para evitar matricular al mismo estudiante dos veces en una sección.
