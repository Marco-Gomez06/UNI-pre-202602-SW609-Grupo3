# 3.2.5. Grupo transversal — Seguridad, configuración y auditoría

> [3.2. Atributos](../3.2.md) › Grupo transversal

Este módulo utiliza los tipos físicos de Microsoft SQL Server.

### `usuario`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `usuario_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del usuario. |
| `correo_institucional` | `VARCHAR(100)` | UQ, NOT NULL | Credencial de acceso institucional. |
| `contrasena_hash` | `VARCHAR(255)` | NOT NULL | Hash criptográfico de la contraseña. |
| `rol` | `VARCHAR(20)` | NOT NULL, dominio `ESTUDIANTE`, `DOCENTE`, `GESTION`, `ADMIN` | Rol y permisos del usuario. |
| `activo` | `BIT` | NOT NULL, valor predeterminado `1` | `1` habilitado y `0` deshabilitado. |

### `parametro_sistema`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `parametro_sistema_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del parámetro. |
| `clave` | `VARCHAR(100)` | UQ, NOT NULL | Nombre único del parámetro. |
| `valor` | `VARCHAR(255)` | NOT NULL | Valor vigente del parámetro. |
| `descripcion` | `VARCHAR(500)` | NOT NULL | Función del parámetro. |
| `usuario_modifica_id` | `INT` | FK → `usuario.usuario_id`, NOT NULL | Último usuario que modificó el parámetro. |
| `fecha_modificacion` | `DATETIME` | NOT NULL | Momento de la última modificación. |

### `auditoria`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `auditoria_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del registro. |
| `usuario_id` | `INT` | FK → `usuario.usuario_id`, NOT NULL | Usuario que ejecutó la operación. |
| `tabla_afectada` | `VARCHAR(100)` | NOT NULL | Tabla sobre la que se operó. |
| `registro_afectado` | `VARCHAR(100)` | NOT NULL | Identificador del registro afectado. |
| `operacion` | `VARCHAR(20)` | NOT NULL, dominio `INSERT`, `UPDATE`, `DELETE` | Tipo de operación. |
| `fecha_hora` | `DATETIME` | NOT NULL | Momento exacto de la operación. |
| `detalle` | `VARCHAR(MAX)` | NULL | Valores anteriores y nuevos. |
