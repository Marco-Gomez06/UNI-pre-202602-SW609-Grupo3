# 3.2.2. Módulo 2 — Docentes, secciones y aulas

> [3.2. Atributos](../3.2.md) › Módulo 2

Este módulo utiliza los tipos físicos de Microsoft SQL Server.

### `docente`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `docente_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del docente. |
| `usuario_id` | `INT` | FK → `usuario.usuario_id`, UQ, NOT NULL | Cuenta de acceso del docente. |
| `facultad_id` | `INT` | FK → `facultad.facultad_id`, NOT NULL | Facultad a la que está adscrito. |
| `codigo` | `VARCHAR(20)` | UQ, NOT NULL | Código del docente. |
| `nombres` | `VARCHAR(100)` | NOT NULL | Nombres del docente. |
| `apellidos` | `VARCHAR(100)` | NOT NULL | Apellidos del docente. |
| `regimen_dedicacion` | `VARCHAR(30)` | NOT NULL, dominio `TIEMPO_COMPLETO`, `TIEMPO_PARCIAL` | Régimen laboral del docente. |
| `categoria` | `VARCHAR(30)` | NOT NULL, dominio `AUXILIAR`, `ASOCIADO`, `PRINCIPAL` | Categoría docente. |

### `aula`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `aula_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del aula. |
| `facultad_id` | `INT` | FK → `facultad.facultad_id`, NOT NULL | Facultad que administra el aula. |
| `codigo` | `VARCHAR(20)` | UQ, NOT NULL | Código del aula. |
| `nombre` | `VARCHAR(100)` | NOT NULL | Nombre descriptivo del aula. |
| `ubicacion` | `VARCHAR(150)` | NOT NULL | Pabellón, piso o referencia. |
| `capacidad` | `INT` | NOT NULL | Aforo máximo del aula. |
| `tipo` | `VARCHAR(20)` | NOT NULL, dominio `TEORIA`, `LABORATORIO`, `TALLER` | Tipo de aula. |

### `seccion`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `seccion_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la sección. |
| `curso_id` | `INT` | FK → `curso.curso_id`, NOT NULL | Curso que se dicta. |
| `ciclo_academico_id` | `INT` | FK → `ciclo_academico.ciclo_academico_id`, NOT NULL | Ciclo en que se dicta. |
| `docente_id` | `INT` | FK → `docente.docente_id`, NOT NULL | Docente responsable. |
| `aula_id` | `INT` | FK → `aula.aula_id`, NOT NULL | Aula asignada. |
| `codigo_seccion` | `VARCHAR(10)` | NOT NULL | Código de la sección. |
| `vacantes_totales` | `INT` | NOT NULL | Capacidad total de la sección. |
| `vacantes_disponibles` | `INT` | NOT NULL, `CHECK >= 0` y `<= vacantes_totales` | Cupos libres disponibles. |
| `modalidad` | `VARCHAR(20)` | NOT NULL, dominio `PRESENCIAL`, `VIRTUAL`, `HIBRIDA` | Modalidad de dictado. |

La combinación `(curso_id, ciclo_academico_id, codigo_seccion)` debe ser única.

### `horario_seccion`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `horario_seccion_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del bloque horario. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección a la que pertenece. |
| `dia_semana` | `TINYINT` | NOT NULL | Día de la semana: 1 = lunes. |
| `hora_inicio` | `TIME` | NOT NULL | Hora de inicio. |
| `hora_fin` | `TIME` | NOT NULL, `CHECK hora_fin > hora_inicio` | Hora de fin del bloque. |
| `tipo_sesion` | `VARCHAR(20)` | NOT NULL, dominio `TEORIA`, `PRACTICA`, `LABORATORIO` | Tipo de sesión. |

### `ampliacion_vacantes`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `ampliacion_vacantes_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único de la solicitud. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección cuya capacidad se amplía. |
| `usuario_solicita_id` | `INT` | FK → `usuario.usuario_id`, NOT NULL | Usuario solicitante. |
| `usuario_aprueba_id` | `INT` | FK → `usuario.usuario_id`, NULL | Responsable que resuelve la solicitud. |
| `cantidad_solicitada` | `INT` | NOT NULL | Vacantes adicionales pedidas. |
| `cantidad_aprobada` | `INT` | NULL | Vacantes efectivamente autorizadas. |
| `motivo` | `VARCHAR(255)` | NOT NULL | Justificación de la solicitud. |
| `estado` | `VARCHAR(20)` | NOT NULL, dominio `PENDIENTE`, `APROBADA`, `RECHAZADA` | Estado de la solicitud. |
| `fecha_solicitud` | `DATETIME` | NOT NULL | Momento de la solicitud. |
| `fecha_resolucion` | `DATETIME` | NULL | Momento de aprobación o rechazo. |

### `demanda_insatisfecha`

| Atributo | Tipo | Restricción física | Descripción |
|---|---|---|---|
| `demanda_insatisfecha_id` | `INT` con `IDENTITY(1,1)` | PK, NOT NULL | Identificador único del registro. |
| `seccion_id` | `INT` | FK → `seccion.seccion_id`, NOT NULL | Sección que estaba llena. |
| `estudiante_id` | `INT` | FK → `estudiante.estudiante_id`, NOT NULL | Estudiante que no logró vacante. |
| `fecha_intento` | `DATETIME` | NOT NULL | Momento del intento. |
| `motivo` | `VARCHAR(30)` | NOT NULL, dominio `SIN_VACANTES`, `RESERVA_VENCIDA` | Motivo de la demanda insatisfecha. |
